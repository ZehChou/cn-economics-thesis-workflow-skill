## Phase 1：选题与文献定位

### 流程

```
用户输入 X / Y / 中介变量 / 研究题目 / 水平
        │
        ▼
AI 检索中英文文献（流程见附录 J）
        │
        ├── L0 元数据 API：OpenAlex / Crossref / Semantic Scholar（英文）
        └── L1 Zotero 中文抓取：知网/万方/维普（用户机构 IP，一键入库）
        │
        ▼
AI 抓取开放获取全文 + 用户补齐机构订阅全文
        │
        ▼
AI 精读 5-10 篇核心文献 + 引用拓扑分析
        │
        ▼
AI 生成：
  ① 文献知识库（关键文献摘要+贡献+方法+数据+结论）
  ② 选题评估报告（可行性 / 创新点 / 数据可得性 / 潜在问题）
        │
        ▼
用户确认 → 进入 Phase 2
```

### Step 1.1：用户输入

AI 引导用户提供以下信息：

1. **被解释变量 (Y)**：是什么？核心测度指标？
2. **核心解释变量 (X)**：是什么？变动的来源？
3. **潜在机制/中介变量 (M)**（可选）：可能通过什么渠道影响？
4. **研究题目/方向描述**：一句话概括
5. **所属学科领域**：劳动经济学 / 产业组织 / 发展经济学 / 金融 / 国际贸易 / 其他

L1 用户额外询问：是否有感兴趣的具体问题或现象？

### Step 1.2：AI 检索文献

> 具体接口、代码、去重与入库规则见**附录 J**。本节只定检索策略。

#### 英文文献（L0：官方 API）

用 OpenAlex 为主、Crossref 补 DOI、Semantic Scholar 补引用关系：

- 搜索关键词：由 AI 基于用户输入生成 3-5 组，含同义扩展（如 `AI` / `artificial intelligence` / `machine learning`）
- 排序：`cited_by_count` 降序，年份限定近 8 年
- 每组成果取 top 20，跨组去重（标题归一化 + DOI）
- 优先关注：近 5 年、高引用、顶刊

核心文献（5-10 篇）的全文按开放获取优先级抓取：

- **OpenAlex `open_access.oa_url`** → 直接可取
- **NBER**（`nber.org/papers/wXXXX`）→ 经济学工作论文，免费
- **SSRN**（`papers.ssrn.com`）/ **arXiv**（`arxiv.org`）→ 多数免费
- **作者个人主页** → 多数经济学家会挂工作论文

#### 中文文献（L1：Zotero 一键抓取，不做爬虫）

**AI 不直接访问知网**（无公开 API、需登录与验证码、反爬严格）。改为：

```
AI 生成 3-5 组中文检索式（含 CSSCI 限定 + 年份 + 主题词同义扩展）
        ↓
用户在知网检索 → 点浏览器 Zotero Connector → 批量入库（题录 + PDF 附件）
        ↓
Zotero 导出 CSL JSON → references/zotero_export.json
        ↓
AI 读取并合并进 citation_db（附录 J.3 / J.5）
```

- 期刊来源限定：**CSSCI 来源期刊**（中文社会科学引文索引），可加"北大核心"
- 排序：按"被引频次"降序 + "时间"降序，取 top 15
- 优先关注：近 5 年、《经济研究》《管理世界》《中国工业经济》《世界经济》等顶刊

> 🛟 降级分支（用户未使用 Zotero / 抓取失败）：AI 输出完整检索式与候选清单，请用户把题录粘贴回来
> 或直接把 PDF 放进 `references/`，AI 从 PDF 首页抽取元数据入库。**不应因访问受限而中断流程**（附录 D.2）。

#### 引用拓扑分析（Citation Topology）

找到一篇核心文献后，AI 应进行引用拓扑分析以扩展文献网络：

```
引用拓扑分析
─────────────────────────────────

向前追溯（引用了本文的文献）：
  英文：OpenAlex `Works().filter(cites="W...")` 或 Semantic Scholar /citations
  中文：知网"引证文献"页 + Zotero 抓取
  了解该研究对后续工作的影响

向后追溯（本文引用的文献）：
  提取参考文献列表，查找重复出现的高引文献
  了解该研究的理论和方法来源

共引分析（与本文共同被引的文献）：
  查找与本文常被一起引用的文献
  发现同一领域的"竞争性"研究

文献簇识别：
  将上述文献按主题/方法聚类
  识别研究脉络中的关键节点
─────────────────────────────────
```

### Step 1.3：文献可信度分级（中文文献版）

中文文献增加以下可信度标识：

```
可信度评估（中文文献版）：
  H = CSSCI 来源期刊 / 高被引 / 国家级基金项目
  M = 核心期刊 / 有一定引用 / 方法可靠
  L = 普通期刊 / 无引用 / 方法存在明显问题
```

### Step 1.4：生成文献知识库

对每篇精读文献，AI 提取以下结构化信息：

```
文献知识库格式（每篇一条）：
────────────────────────────────────────
标题：{Title}
作者：{Authors}（{Year}）
期刊/来源：{Journal/Source}（{CSSCI / SSCI / SCI / 其他}）
引用数：{Citations}
────────────────────────────────────────
研究问题：{Research Question}
核心发现：{Main Findings}
数据来源：{Data Source}
方法：{Methodology}
估计策略：{Identification Strategy}
与本题关联：{Relevance to Our Topic}
────────────────────────────────────────
关键引用句（可直接用于文献综述的段落）：
"{Quote}"
────────────────────────────────────────
可信度评估：[H/M/L]
  H = 顶级期刊 / 高引用 / 方法严谨
  M = 领域内重要但存在方法争议
  L = 低质量 / 非学术来源
```

### Step 1.5：生成选题评估报告

AI 基于文献扫描结果生成：

```
选题评估报告
═══════════════════════════════════════

1. 可行性评估
   • 已有文献基础：{已有多少相关研究，中外文献比例}
   • 创新空间：{已有研究的缺口，本题的新颖之处}
   • 数据可得性：{常见数据来源建议}
   • 方法可行性：{可用的识别策略}

2. 潜在贡献
   • 理论贡献：{对机制/理论的推进}
   • 实证贡献：{对估计策略/数据的改进}
   • 政策贡献：{对现实问题的启示}

3. 风险提示
   • {潜在的内生性问题}
   • {可能的数据限制}
   • {领域内竞争程度}
   • {其他需要注意的问题}

4. 与范文的比较
   • {范文的定位与本选题的异同}
```

### Step 1.6：用户确认

用户阅读后可以：
- ✅ **确认**——进入 Phase 2
- ✏️ **修改**——调整题目方向或变量
- ❌ **放弃**——重新选题

### 状态更新

Phase 1 完成后，更新 `.thesis_state.json`：
- `current_phase`: 1 → 2
- `citation_db`: 填充文献知识库内容（中英文文献分开记录）
