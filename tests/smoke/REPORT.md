# 冒烟测试报告：9 阶段端到端流程

- 测试日期：2026-10-19
- 测试目标：验证"用户只提供数据、其余由 Agent 完成"的契约能否端到端产出学位论文 docx
- 测试对象：本仓库 `SKILL.md` 与 `phases/` `appendices/` 全量文档
- 结论摘要：**流程完整运行，产物可交付；测试中发现 2 项阻断级缺陷与 9 项影响可信度的缺陷，均已修复并重跑验证**

## 一、测试设计

### 1.1 场景

| 项目 | 设定 |
|---|---|
| 论文题目 | 低碳城市试点政策对企业绿色创新的影响 |
| 样本 | 2010—2022 年 A 股制造业上市公司，500 家，非平衡面板 |
| 政策结构 | 三批试点（2010 / 2012 / 2017），另有从未试点城市作为对照 |
| 被解释变量 | `green_pat`（绿色专利申请量加一取对数），替换度量 `green_inv` |
| 核心解释变量 | `did`（企业所在城市已进入试点且年份不早于试点年） |
| 控制变量 | `size` `lev` `roa` `growth` `age` `cash` |
| 机制变量 | `fc`（融资约束）、`gi`（绿色注意力） |
| 异质性维度 | `soe`（产权性质）、`heavy`（重污染行业） |
| 用户水平 | L2 |
| 计量后端 | Python（后端 B，默认） |
| 排版路线 | P（python-docx） |

### 1.2 数据性质（重要）

数据由 `scripts/gen_data.py` 按预设数据生成过程（DGP）构造，**全部为合成数据**：

- 真实政策效应设为 0.12 个对数点，并设定重污染行业更强、国有企业更弱；
- 机制变量 `fc`、`gi` 受政策影响，但**未被写入结果变量方程**——即真实间接效应为零，
  用于检验流程能否如实报告"机制证据不足"，而非一律宣称机制成立；
- 随机种子固定为 `20240601`，重跑逐字节一致。

论文正文、摘要与封面均明确披露数据为合成数据。**全部数值不具现实含义，不得引用。**

### 1.3 QA 角色由子代理模拟

由子代理扮演用户侧 QA，在 Phase 0—9 的检查点上作出选择，输出 `decisions.json`
（用户水平、计量后端、排版路线、变量清单、模型设定、内生性方法、稳健性检验项、
机制方法、异质性维度、章节大纲、引用体系）。主代理据此执行，不再向人类用户追问。

## 五、复现方法

```bash
cd tests/smoke
python scripts/gen_data.py          # 生成合成数据（固定种子）
python scripts/run_all.py           # 依次执行文献检索与 00—08（需联网）
python scripts/run_all.py --offline # 离网时跳过检索，复用已有 citation_db
```

目录约定：`src/lit_review.md` 为人工撰写的综述底稿（含 `[CIT:]` 占位符，入库）；
`references/`、`thesis/`、`output/`、`log/`、`cleaned/` 均为生成物，不入库，可由上述命令重建。

环境：Python 3.13，pandas 3.0.3、pyfixest 0.60.0、linearmodels 7.1、statsmodels 0.14.6、
scikit-learn、python-docx、matplotlib。文献检索仅依赖标准库 `urllib`，无需额外客户端。

## 六、结论

1. **契约可兑现**：在"用户只给数据 + 回答选择题"的条件下，流程可自动产出结构完整、
   版式合规、数值可追溯的学位论文 docx。
2. **数值可追溯**：正文每个数字均可回溯至 `output/tables/*.csv`，规格日志覆盖 P4—P8。
3. **主要风险不在流程，而在工具接口与结论分寸**：本次两项 P0 分别来自第三方库接口漂移
   与"把部分证据表述为完整结论"。前者需要文档定期复核，后者需要研究诚信纪律（附录 D.5）
   在生成环节强制执行。
4. **Python 后端的真实边界**：常规配置全覆盖；异质性稳健的交叠 DID、Bacon 分解、
   断点回归须转后端 A。该边界已写入附录 H.9 与 Phase 5。
